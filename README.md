# 100k-stronghold-summary

A web UI upgrade for **Couriway's 100K Stronghold Summary** — turning the raw stronghold data into a browsable, Minecraft-themed experience.

**Live:** https://l-ubu.github.io/100k-stronghold-summary/

## Features

- Minecraft-themed design with animations
- Searchable, sortable, and collapsible tables
- Single-page static site — no build step, no dependencies

## Running locally

It's a single `index.html` + `style.css` — just open it:

```bash
open index.html
```
